# AI coding agent instructions

Read this file first, then `docs/AI_HANDOVER.md`, `docs/CURRENT_STATUS.md`, and `docs/SYSTEM_ARCHITECTURE.md` before changing the project. Read feature-specific documentation before changing a feature.

- Inspect existing code and Git status before making assumptions.
- Follow decisions in `docs/DECISIONS.md` and enforce cooperative isolation server-side.
- Avoid unnecessary dependencies and preserve existing functionality.
- Run relevant checks after changes and update affected documentation in the same milestone.
- Never describe planned or untested work as implemented; never invent test results.
- Never expose credentials or commit real `.env` files or secrets.
- Report modified files, actual checks, known issues, and the next task.

If documentation conflicts with implementation, inspect the code and correct the documentation.

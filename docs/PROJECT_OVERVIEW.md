# Project overview

**Status: Planned product; Milestone 1 foundation only.**

Livestock Trust is a Kenyan livestock identification, verification, and productivity-monitoring platform initially focused on dairy cooperatives. The MVP will help cooperatives manage farmers, animals, veterinary and breeding records, milk production, field interventions, dashboards, and reports.

Marketplace transactions, escrow, financing, insurance, blockchain, GPS tracking, and AI diagnosis are outside the initial MVP.
